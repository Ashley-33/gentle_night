# 🌙 Gentle Night · 温柔夜记

> 你的状态，正在被温柔看见。
> *Your state, gently seen.*

一个温柔治愈的**夜间心情记录**网页应用。每天睡前只花 10 秒，为「心情 / 身体 / 期待」三件事打个分，投下三颗珠子；日积月累，罐子里的珠子会汇成一片只属于你的星光，一眼就能看见最近大概的状态。

🔗 **在线体验**：开启 GitHub Pages 后访问 `https://ashley-33.github.io/gentle_night/`

---

## ✨ 功能特性

- **每日记录**：每天一次，为 Mood（心情）、Body（身体）、Tomorrow（期待）三项打 1–5 分，点「晚安」即收下。
- **珠子可视化**：每条记录在对应罐子里化作一颗珠子
  - 分数越高，颜色越浓郁；越低越偏中性灰 —— **一眼看浓淡，便知近况**
  - 「很好（5 分）」的珠子还会亮起**柔和的星芒闪烁** ✨
  - 珠子用「逐颗下落 + 碰撞落位」算法**自然堆叠**，新珠在顶、旧珠在底
- **时间维度**：7 天 / 30 天 / 3 个月 / 1 年，随时回看不同区间。
- **温柔评语**：罐底文案根据区间内的**平均分**自动生成（低 / 中 / 高三档）。
- **疗愈文案**：顶部与底部各有 50 组中英文「小语」，每次随机展示。
- **落入动效 + 音效**：点「晚安」时浮现玻璃罐，三颗珠子逐颗落入、盖上木盖、缓缓升起，配柔和的水滴铃音（Web Audio 合成，无需音频文件）。
- **双主题**：浅色 / 深色，**默认跟随系统**，也可右上角一键手动切换并记住选择。
- **响应式网页**：手机满宽铺满，桌面居中成栏，一屏到位、优雅不滚动。

## 🎨 设计语言

- **柔雾高级色**（莫兰迪风）：奶蜜黄 / 雾感沙绿 / 灰调薰衣草，低饱和、奶雾感。
- **真实感玻璃罐**：通透玻璃 + 边缘镜面高光 + 原木盖 + 罐底投影，纯 SVG/CSS 绘制。
- **手绘萌系图标**：微笑太阳、有表情的叶子、微笑星星，内联 SVG，随主题发光。
- **月牙、星光**：以柔和暖光营造夜晚的安心感。

## 🧠 数据与逻辑

- **纯前端**，数据全部保存在浏览器 `localStorage`，**不上传任何服务器**：
  ```js
  "gentle-night.entries" = [{ date:"2026-06-04", mood:4, body:4, tomorrow:3 }, …]
  "gentle-night.theme"   = "light" | "dark"
  ```
- 每天一条记录，**当天重复提交会覆盖**；重新打开会回填今天已记录的分数。
- 时间范围按本地日期筛选；超过约 70 颗时均匀采样展示。

> 🔒 **隐私**：所有数据只存在你自己的设备上，清除浏览器数据即清空。

## 🚀 本地运行

无需构建、无依赖，任选一种方式打开：

```bash
# 方式一：用 Python 起一个静态服务器
cd gentle_night
python3 -m http.server 4180
# 然后浏览器打开 http://localhost:4180

# 方式二：直接用浏览器打开 index.html 亦可
```

## ☁️ 部署到 GitHub Pages

1. 仓库 **Settings → Pages**
2. Source 选 **Deploy from a branch**，分支选 **`main`** / **`/ (root)`**
3. 保存，稍等一两分钟即可通过 `https://ashley-33.github.io/gentle_night/` 访问。
